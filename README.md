# Tic-Tac-Toe Game

## Description

This is a simple Tic-Tac-Toe game implemented in Java using Swing for the graphical user interface (GUI). The game allows two players to take turns and marks their moves with "X" and "O". The game checks for a winner or a tie and displays a message accordingly.

## Features

- Two-player gameplay
- Winner detection
- Tie detection
- Reset functionality

## Requirements

- Java Development Kit (JDK) 8 or later

## Usage

- **Start the game**: Run the `TicTacToe` class.
- **Play**: Click on any cell to place your mark ("X" or "O").
- **Win or Tie**: The game will automatically detect and announce the result.
